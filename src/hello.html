🔗 ファイルアクセス方法

📁 ファイル配置場所

すべてのファイルは /src フォルダに配置してください：

/src/ ├── index.php ← メインのPHPファイル ├── api.php ← API エンドポイント ├── hello.html ← このHTMLファイル ├── js-api-demo.html ← JavaScript APIデモ ├── assets/ ← 静的ファイル │ ├── css/ │ │ └── main.css ← スタイルシート │ └── js/ │ ├── api.js ← API通信ライブラリ │ ├── demo.js ← デモページ用 │ └── hello.js ← このページ用 └── images/ ← 画像ファイル
