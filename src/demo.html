🎯 シンプルデモページ

HTML作業者向け：JavaScriptの関数を呼び出すだけでデータベース操作ができます！

💡 使い方

下記のボタンを押すだけで、データベースからデータを取得・表示できます。
コードをコピーして、あなたのプロジェクトで使用してください！

👥 ユーザー一覧表示

データベースからユーザー情報を取得して表示します。

// HTML作業者向けのコード例 <button onclick="showUsers('users-display')">ユーザー一覧</button> <div id="users-display"></div> <script src="/assets/js/demo.js"></script>

➕ 新規ユーザー登録

// ユーザー登録のコード例 <form id="user-form"> <input type="text" name="name" placeholder="名前" required> <input type="email" name="email" placeholder="メール" required> <button onclick="addUserFromForm('user-form', 'user-status')">登録</button> </form> <div id="user-status"></div> <script src="/assets/js/demo.js"></script>

📝 投稿一覧表示

データベースから投稿情報を取得して表示します。

// 投稿一覧表示のコード例 <button onclick="showPosts('posts-display')">投稿一覧</button> <div id="posts-display"></div> <script src="/assets/js/demo.js"></script>

✍️ 新規投稿作成

※ 実際の開発では、ログインユーザーのIDを使用
// 投稿作成のコード例 <form id="post-form"> <input type="number" name="user_id" value="1" required> <input type="text" name="title" placeholder="タイトル" required> <textarea name="content" placeholder="内容"></textarea> <button onclick="addPostFromForm('post-form', 'post-status')">投稿</button> </form> <div id="post-status"></div> <script src="/assets/js/demo.js"></script>

🎯 HTML作業者向けのポイント

  • PHPは不要: /assets/js/demo.js を読み込むだけ
  • 関数呼び出し: onclick="showUsers('target-id')" で簡単操作
  • 自動表示: 結果は自動的に指定した場所に表示される
  • フォーム処理: addUserFromForm() で簡単送信

📋 完全なHTMLサンプル

<!DOCTYPE html> <html lang="ja"> <head> <meta charset="UTF-8"> <title>あなたのプロジェクト</title> <link rel="stylesheet" href="/assets/css/main.css"> </head> <body> <div class="container"> <h1>ユーザー管理</h1> <!-- ユーザー一覧表示ボタン --> <button onclick="showUsers('user-list')">ユーザー一覧表示</button> <div id="user-list"></div> <!-- ユーザー登録フォーム --> <form id="register-form"> <input type="text" name="name" placeholder="名前" required> <input type="email" name="email" placeholder="メール" required> <button type="button" onclick="addUserFromForm('register-form', 'result')">登録</button> </form> <div id="result"></div> </div> <!-- 重要：このファイルを読み込む --> <script src="/assets/js/demo.js"></script> </body> </html>
